Guardado local y copias de seguridad

Guardado local: las recetas y los ingredientes se guardan automáticamente en el almacenamiento del navegador de este dispositivo. No se suben automáticamente a internet ni se comparten con otros usuarios.

Para guardar una copia de tus recetas:

  1. Entrá en Mis recetas.
  2. Tocá Exportar respaldo. Se descargará un archivo llamado respaldo_formulador_salsas.json (el nombre puede variar si guardás varias copias).
  3. Guardá ese archivo en un lugar seguro, por ejemplo en tu carpeta de documentos o en tu nube personal.

Para recuperar las recetas o pasarlas a otro dispositivo:

  1. Abrí el Formulador en el otro dispositivo y entrá en Mis recetas.
  2. Tocá Importar respaldo y elegí el archivo JSON que exportaste.
  3. Confirmá la importación. Atención: la importación reemplaza los datos locales que haya en ese navegador; exportá primero un respaldo de esos datos si querés conservarlos.
Importante: el almacenamiento local puede perderse si borrás los datos del navegador, usás otro navegador/dispositivo o el navegador restringe el almacenamiento de archivos locales. Exportá respaldos periódicamente. Para compartir datos en tiempo real entre varios usuarios se necesitaría una versión conectada a una base de datos en la nube.
